# DNSA — Anos e Modelos de Motos

Site estático pronto para GitHub Pages.

## Publicar
1. Extraia o ZIP.
2. Envie o conteúdo da pasta `dnsa-anos-modelos` para a raiz do repositório.
3. No GitHub, abra **Settings > Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch** e publique a branch principal pela pasta `/ (root)`.

## Recursos
- Busca por modelo, montadora e cilindrada.
- Montadoras na ordem fixa: Honda, Yamaha, Suzuki, Shineray, Dafra, Haojue e Traxx.
- Cilindradas em ordem crescente.
- Logos ficam dentro da pasta `assets/logos` e não dependem de internet externa para aparecer.
- Seleção múltipla de modelos, acumulando um por linha.
- Formato simplificado e discriminado.
- Botão para copiar texto e botão para limpar todas as motos selecionadas.
- Selecionar uma moto não rola a página automaticamente.

## Base
Os dados ficam em `data.js`.
